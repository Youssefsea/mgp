# Mohamed Gamal — DevOps Portfolio

Single-page Next.js + TypeScript portfolio. The entire UI lives in `app/page.tsx`.

## Run
```bash
npm install
npm run dev
```

Add the personal portrait at `public/profile.jpg` and CV at `public/cv.pdf`.

The experience/certification organization logos are referenced from Wikimedia Commons / DEPI public image hosting; the page does not require them to be bundled locally.
